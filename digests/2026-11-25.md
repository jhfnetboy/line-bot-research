## LIFF / LINE MINI App (breaking)

### LINE now blocks old LIFF SDK versions v2.20.0 to v2.31.0: liff.login() fails and fixed CDN paths return 403

In a notice dated Nov 24 and updated Nov 25, LINE Developers says it has carried out the usage restrictions announced on Oct 20 for LIFF SDK versions with a confirmed vulnerability (v2.20.0 to v2.31.0). Since Nov 24, liff.login() requests from those versions fail in external browsers and LINE's in-app browser, so affected LIFF apps and LINE MINI Apps may stop working. Since Nov 25, loading those versions from a CDN fixed path returns HTTP 403, so the script tag errors; LINE says it may take a day or more to take effect depending on user environment and cache. The CDN block does not cover the npm package, so npm users must still update. Fix: the CDN edge path (liff/edge/2/sdk.js) is already on v2.32.0; fixed-path users should load versions/2.32.0/sdk.js; npm users should run npm install @line/liff@2.32.0 (minimum safe version is v2.31.1).

## AI bots on LINE (Japan)

### ABEJA adds free-form LLM chat with real estate ad rule checks to the 'CHINTAI Agent' LINE service

CHINTAI Agent is a rental search service with over 1 million LINE friends. Users can now type their wishes and questions freely on LINE and get property suggestions from an AI built on about 100,000 past human chat logs, with ABEJA's rental ad review AI checking the text against Japan's real estate ad display rules. ABEJA says generation now references the rules up front, uses multi-stage guardrails and auto-replaces risky phrases, cutting response time from several minutes (up to 10 or more) to a median of about 16 seconds. A useful pattern for anyone running LLM replies in a regulated industry on LINE.

- Source: https://prtimes.jp/main/html/rd/p/000000244.000010628.html (2026-11-24)

## Government OA (Japan)

### Fujimino City plans an AI concierge, segment delivery and a tabbed rich menu for its LINE OA from Feb 1, 2027

Fujimino, Saitama, says its expanded LINE OA will answer residents' questions 24 hours a day using content from the city website, let followers pick categories such as child-rearing, events and disaster prevention instead of receiving every broadcast, split the rich menu into category tabs, send next-day garbage collection reminders for the user's area, and accept road and park problem reports with a photo and location. Start date is Feb 1, 2027.

- Source: https://prtimes.jp/main/html/rd/p/000000255.000099719.html (2026-11-24)

### Ichinomiya City libraries open a LINE OA today with catalog search, reservations and a digital library card

From 9:00 on Nov 25, Ichinomiya, Aichi, runs a library LINE OA for search and reservations across five libraries. Linking a LINE account to the library user number shows the barcode library card without entering the number and password, and sends reservation notices and checkout notices in place of printed receipts. The city also starts online provisional user registration and online address or name changes.
